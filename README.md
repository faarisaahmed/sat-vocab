# SAT Vocab

Flashcard viewer for the vocab words from Barron's SAT Flash Cards (2008), numbered to match the physical cards. The definitions, examples, synonyms and root notes are original. Plain HTML/CSS/JS, no build step.

- **Cards**: click or press space to flip, ← → to move, shuffle, search
- **My collection**: each person types in the physical cards they picked up (or deals random new ones). Cards sit in an *In training* pile until you mark their words *Def know*. Focus on red, grey or both. A shared *Don't know* list holds words nobody knows. Saved in the browser on this device.
- **All words**: scrollable list of every word with definition and example

Cards live in `data/vocab.js`. Edit that file to add or change words.
